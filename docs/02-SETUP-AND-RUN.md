# التشغيل من الكود المصدري

## المتطلبات

- **Python 3.9** — يُفضَّل بشدة استخدام هذا الإصدار تحديدًا إن كان الهدف التوافق مع Windows 7 (هو آخر إصدار رسمي بمثبِّت Windows 7). على Windows 10/11 يمكن استخدام أي إصدار 3.9 حتى 3.12.
  - حمّله من: https://www.python.org/downloads/release/python-3913/ (اختر "Windows installer" المناسب لمعمارية الجهاز)
- بعد التثبيت، تأكد بتنفيذ: `python --version`

## خطوات التشغيل

1. افتح Terminal / Command Prompt داخل مجلد `python-app`.
2. أنشئ بيئة افتراضية (اختياري لكن مُوصى به):
   ```bash
   python -m venv venv
   # على Windows:
   venv\Scripts\activate
   # على Linux/Mac:
   source venv/bin/activate
   ```
3. ثبّت الحزم المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
4. شغّل التطبيق:
   ```bash
   python main.py
   ```
5. عند أول تشغيل، سيتم تلقائيًا:
   - إنشاء قاعدة بيانات SQLite جديدة في مجلد بيانات المستخدم.
   - تعبئة البيانات المرجعية: كتالوج التحاليل (954 تحليل)، الأسعار (2289 سعر)، المدى الطبيعي، الأقسام، جهات الإحالة، الأدوار، ومستخدم `admin` افتراضي.
6. ستظهر شاشة تسجيل الدخول:
   ```
   اسم المستخدم: admin
   كلمة المرور:   Admin@123
   ```

## مكان قاعدة البيانات والملفات المُولَّدة

```
Windows: C:\Users\<اسم المستخدم>\AppData\Roaming\LapLIS-Python\laplis.db
Linux/Mac: ~/.config/LapLIS-Python/laplis.db
```

مجلدات فرعية تُنشأ تلقائيًا بجانبها:
- `Invoices/` — نسخ PDF من كل فاتورة.
- `Reports/` — نسخ PDF من تقارير نتائج التحاليل.

## إعادة التشغيل من الصفر

لتجربة قاعدة بيانات فارغة تمامًا، احذف مجلد `LapLIS-Python` المذكور أعلاه، ثم شغّل `python main.py` من جديد.

## تصدير/استيراد الكتالوج (نسخ احتياطي أو تعديل جماعي)

أداة سطر أوامر `cli.py` تصدّر أو تستورد جداول الكتالوج الأساسية (الأدوار، الصلاحيات، المستخدمون، الأقسام، التحاليل، الأسعار) كملف JSON واحد:

```bash
python cli.py export backup.json
python cli.py import backup.json   # سيطلب تأكيدًا لأنه يستبدل الجداول بالكامل
```

**تحذير**: `import` عملية **استبدال كامل** لكل جدول موجود في الملف (تحذف كل الصفوف الحالية ثم تُدخِل صفوف الملف) — خذ نسخة احتياطية من مجلد البيانات قبل استخدامها.

## تشغيل الاختبارات الآلية

```bash
pip install pytest   # مُدرَجة بالفعل في requirements.txt
pytest -q
```

الاختبارات معزولة تمامًا عن قاعدة بياناتك الحقيقية (تستخدم قاعدة بيانات مؤقتة لكل اختبار)، فتشغيلها آمن في أي وقت.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `python: command not found` | Python غير مثبَّت أو غير مضاف لمتغيرات النظام (PATH) — أعد تثبيته وفعّل خيار "Add Python to PATH" |
| رسالة عن `Qt platform plugin "xcb"` (على Linux فقط) | ثبّت `libxkbcommon-x11-0` عبر مدير الحزم (`apt-get install libxkbcommon-x11-0`) |
| النصوص العربية تظهر متقطعة في الواجهة | نادر الحدوث مع Qt (تعالج العربية أصليًا)؛ تأكد أن `arabic-reshaper` و`python-bidi` مثبَّتان بشكل صحيح لو المشكلة في ملفات PDF فقط |
| رسالة `ModuleNotFoundError` | نفّذ `pip install -r requirements.txt` مرة أخرى، وتأكد أن البيئة الافتراضية مفعّلة |
